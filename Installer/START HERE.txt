BLADESONG MOD MANAGER — STANDALONE CANDIDATE

Includes configured UE4SS and BladesongModManager. No framework is required.
Close Bladesong. Extract All. Open the extracted folder. Run INSTALL.cmd.
Choose your Steam Bladesong game folder if asked. Start the game and click Mods.
SDK mods such as PCL may require BladesongModFramework; the manager resolves that dependency when installing the mod.
Existing saves, libraries and framework files are not replaced by this package.
